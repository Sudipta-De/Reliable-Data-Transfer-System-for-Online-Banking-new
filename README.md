# 🏦 Reliable Data Transfer System for Online Banking

A Cisco Packet Tracer simulation project demonstrating a **reliable data transfer system for online banking** using a client-server architecture. The project focuses on secure and reliable communication between banking branches through dynamic routing, error detection concepts, and network connectivity.

---

## 📌 Project Overview

This project was developed as part of the **Computer Networks Project Based Learning (PBL)** assignment. It simulates an online banking environment where multiple branch offices communicate with a central banking server over a reliable network infrastructure.

The network is designed to ensure successful transmission of banking data while demonstrating key concepts such as routing, connectivity verification, and reliable communication.

---

## 🎯 Objectives

- Design a secure banking network using Cisco Packet Tracer.
- Simulate communication between Head Office and Branch Offices.
- Demonstrate reliable data transfer in a client-server environment.
- Perform CRC (Cyclic Redundancy Check) calculations for error detection.
- Verify successful communication through network testing.

## 🚀 How to Run

1. Install **Cisco Packet Tracer**.
2. Clone this repository.
3. Open the `.pkt` file in Cisco Packet Tracer.
4. Wait for the devices to initialize.
5. Verify routing tables.
6. Test connectivity using `ping`.
7. Observe packet flow in Simulation Mode.
